# やじるし ぱずる

小学1年生向けのプログラミング学習ウェブアプリ（試作）。

- 矢印カード（まえ・みぎ・ひだり・くりかえし）を並べて、キャラ「ぴよ」を⭐まで動かすパズル
- 全3問。画面の文字はひらがなのみで、音声で読み上げる
- 問題を解くと果物がもらえて、食べさせるとぴよが成長する（進み具合はブラウザに保存）

## 遊び方
`index.html` をブラウザで開くだけ。外部ライブラリは使っていない。

## GitHub Pages で公開
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にする。
