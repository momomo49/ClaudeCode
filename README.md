# やじるし ぱずる

小学1年生向けのプログラミング学習ウェブアプリ（試作）。

- 矢印カード（まえ・みぎ・ひだり・くりかえし）を並べて、キャラ「ぴよ」を⭐まで動かすパズル
- 3コース × 8問 = 24問
  - かんたん（5×5）：まえ・みぎ・ひだり だけ。カードに余裕あり
  - ふつう（6×6）：くりかえし が登場。くだもの集めも
  - むずかしい（6×6）：カードの枚数が最短ぴったり。めいろ・くだもの3こ
- 失敗するとヒントが出る（1回目: 足あとで通り道 / 2回目: 答えのカード）
  - 答えとカード上限は、プログラムが自動で最短手を計算して決める
- 画面の文字はひらがなのみで、音声で読み上げる
- 初めて解いた問題で果物がもらえて、食べさせるとキャラが成長する（5段階、進み具合はブラウザに保存）
- キャラはメニューで選べる（にゃんこ／ぴよ／うさぴょん）。画像は `img/{動物}_{1〜5}.png`（384px・背景透明）

## 問題の足し方
`index.html` の `COURSES` に、文字の地図を1つ足すだけ。
`.` みち / `#` いわ / `G` ほし / `F` くだもの / `^ > v <` スタートと向き

## 遊び方
`index.html` をブラウザで開くだけ。外部ライブラリは使っていない。

## GitHub Pages で公開
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にする。
